# ربات تلگرام Do It (انجامش بده) 🎯

یک ربات تلگرام سبک، قدرتمند و هوشمند برای یادآوری کارها و رویدادها، با پشتیبانی کامل از **زبان فارسی**، **تقویم شمسی (جلالی)**، **تقویم میلادی**، و **زمان‌بندی‌های تکرارشونده و نسبی**.

---

## 🌟 ویژگی‌های کلیدی

- **جداسازی کاملاً منعطف (با یا بدون `+`):**
  - با علامت `+`: `خرید نان + ساعت ۷ عصر`
  - بدون `+` (طبیعی و روان): `فردا ساعت ۶ برم دکتر` یا `ساعت ۱۰ شب به مامان زنگ بزن`
  - تاریخ در متن: `۲۵ مهر جلسه اولیا و مربیان` یا `15 November send report`
- **پشتیبانی دوگانه از تقویم جلالی (شمسی) و میلادی:**
  - شمسی: نام ماه‌ها (`۲۵ مهر ماه`، `اول آبان`) و فرمت‌های عددی (`۱۴۰۵/۰۷/۲۵`)
  - میلادی: نام ماه‌ها به فارسی و انگلیسی (`25 October ساعت ۴ بعد از ظهر`، `15th Nov`، `2026-10-25`)
- **زمان‌های نسبی و دوره‌ای (Recurrence):**
  - نسبی: `۱۰ دقیقه دیگه`، `نیم ساعت دیگه`، `یک ربع دیگه`، `۲ ساعت بعد`
  - تکرار روزانه: `هر روز ساعت ۷ صبح`
  - تکرار روزهای زوج/فرد: `روزهای زوج ساعت ۵ عصر` (شنبه، دوشنبه، چهارشنبه)، `روزهای فرد`
  - تکرار هفتگی و ماهانه: `هر هفته پنج شنبه ۸ شب`، `هر ماه ۲۵ ام`
- **حالت‌های لبه (Edge Cases):**
  - پشتیبانی از تمام ارقام فارسی (`۰-۹`) و عربی (`٠-٩`)
  - مدیریت خودکار نیم‌فاصله‌ها (`پنج‌شنبه` و `پنج شنبه`)
  - اعداد حروفی پرکاربرد (`هفت و نیم شب`، `یک ربع به ۹`)
  - مدیریت زمان‌های گذشته با پیشنهاد موعد پیش‌رو
- **ماندگاری دائمی (Persistence):**
  - ذخیره‌سازی در **SQLite**؛ در صورت ری‌استارت یا قطعی اینترنت هیچ یادآوری از بین نمی‌رود و یادآوری‌های گذشته هنگام اتصال مجدد تحویل داده می‌شوند.
- **دکمه‌های تعاملی اعلان (Interactive Inline Keyboard):**
  - `✅ انجام شد`
  - `⏰ ۵ دقیقه بعد` / `⏰ ۱۵ دقیقه بعد` / `⏰ ۱ ساعت بعد` / `⏰ فردا همین ساعت` (اسنوز هوشمند)
  - `❌ لغو یادآوری`

## 🚀 راهنمای نصب و راه‌اندازی سریع

### ۱. پیش‌نیازها
- پایتون نسخه ۳.۱۱ یا بالاتر
- ابزار `uv` یا `pip`

### ۲. ساخت توکن ربات در تلگرام
۱. در تلگرام وارد ربات [@BotFather](https://t.me/BotFather) شوید.
۲. دستور `/newbot` را بفرستید.
۳. نام نمایشی (مثلاً `Do It`) و یوزرنیم بات (مثلاً `MyDoItReminderBot`) را انتخاب کنید.
۴. **توکن API (HTTP API Token)** دریافتی را کپی کنید.

### ۳. تنظیم متغیرهای محیطی
فایل نمونه `.env.example` را به `.env` تغییر نام دهید یا یک فایل `.env` در پوشه ریشه بسازید:

```bash
cp .env.example .env
```

سپس داخل فایل `.env`، توکن خود را قرار دهید:

```env
TELEGRAM_BOT_TOKEN=your_bot_token_here
DEFAULT_TIMEZONE=Asia/Tehran
DATABASE_PATH=do_it.db

# در صورت نیاز به استفاده از پروکسی (اختیاری):
# PROXY_URL=socks5://127.0.0.1:1080
```

### ۴. نصب وابستگی‌ها و اجرای ربات

با استفاده از `uv`:
```bash
uv venv
uv pip install -r pyproject.toml
.venv/bin/python bot/main.py
```

یا با استفاده از `pip`:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
python bot/main.py
```

## 📖 نمونه فرمت‌های قابل ارسال به ربات

| نوع یادآوری | نمونه پیام | نتیجه |
| :--- | :--- | :--- |
| **ساعت روز** | `خرید نان + ساعت ۷ عصر` یا `خرید نان ساعت ۷ عصر` | ساعت ۱۹:۰۰ امروز |
| **روز بعد** | `فردا ساعت ۶ برم دکتر` | ساعت ۱۸:۰۰ فردا |
| **تکرار روزانه** | `ورزش + هر روز ۷ صبح` | هر روز راس ساعت ۰۷:۰۰ |
| **روز مشخص هفته** | `پنج شنبه ۷ بعد از ظهر رفتن به استخر` | پنج‌شنبه آینده ساعت ۱۹:۰۰ |
| **تقویم شمسی** | `۲۵ مهر جلسه اولیا و مربیان` | ۲۵ مهرماه ساعت ۰۹:۰۰ |
| **تقویم میلادی** | `25 October ساعت ۴ بعد از ظهر ارسال ایمیل` | ۲۵ اکتبر ساعت ۱۶:۰۰ |
| **زمان نسبی** | `چک کردن فر + ۱۰ دقیقه دیگه` | ۱۰ دقیقه بعد |
| **اسنوز و کسری** | `نیم ساعت دیگه به علی زنگ بزن` | ۳۰ دقیقه بعد |
| **روزهای زوج** | `کلاس زبان + روزهای زوج ساعت ۵ عصر` | شنبه، دوشنبه، چهارشنبه ساعت ۱۷:۰۰ |
| **روزهای فرد** | `ورزش + روزهای فرد ساعت ۸ شب` | یکشنبه، سه‌شنبه، پنج‌شنبه ساعت ۲۰:۰۰ |

## 📋 دستورات ربات

- `/start`: شروع کار با ربات و مشاهده پیام خوش‌آمدگویی و مثال‌ها
- `/list`: مشاهده لیست تمام یادآوری‌های فعال با امکان لغو هرکدام
- `/help`: راهنمای جامع فرمت‌های زمانی
